# Monopoly-live Map

Based on a real life event where we play monopoly with the locations within London. Given a small book with all the locations and rules of the game I combined all those rules into a website used in the event

Constructed with the Google Maps API, the points are marked on the map. The intention for a better visual aid to plan a better route and track in-game currency as well as housing and renting rules. 

Features include a GPS API to allow mobile users to follow an icon that represents their current location the map. 

A window that allows you to plan a route while calculating distances and total walking time of routes.

Allows for an import of a predetermined path with a JSON file. A separate program was made with a Travelling Sales Man algorithm to give a close to optimal path.

A filtration system to look at points of a specific colour row or station. Allows to see the train lines as a toggle to better plan
